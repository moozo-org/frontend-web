# Frontend Web

## Start project

### PROD

```
docker compose -f docker-compose.prod.yml up -d --build
```

### DEV

```
docker compose -f docker-compose.dev.yml up -d --build
```

### LOCAL

```
docker compose -f docker-compose.local.yml up --build
```

## Technologies

- React
- TypeScript
- Vite
- Prettier
